## 1. 인트로 (1분) — "왜 D-Connect인가요"

> 대전·세종·충남에는 작지만 의미 있는 사회적 기업과 협동조합이 많습니다.
> 환경, 지역 농가, 청년 일자리, 시니어 디지털 격차 — 좋은 활동을 하고 있는데
> **그 활동을 콘텐츠로 알리는 일이 너무 어렵습니다.** 사진 한 장 찍기도 빠듯하니
> SNS 글, 카드뉴스, 보도자료까지 만들 여력이 없죠.
>
> D-Connect는 그 작업을 **AI가 대신 해주는 도구**입니다. 기업의 활동을 입력하면
> Anthropic Claude가 **유엔 지속가능발전목표(SDGs)**와 연결해 콘텐츠 초안을 만들어드립니다.
> 발표하시는 분이 직접 보시면 더 빠르겠죠. 지금부터 화면 보여드릴게요.

**키 메시지**: 작은 기업이 가진 좋은 이야기를 SDGs라는 글로벌 언어로 빠르게 콘텐츠화

## 2. 가입·로그인 (1분)

### 동선
1. 시크릿 창 열기 → `http://localhost:3000` 접속
2. 자동으로 `/login` 이동 — 한국어 안내 + 카카오·구글 로그인 버튼
3. **"회원가입"** 클릭 → 회원가입 폼 보여주기 (이메일·이름·전화·소속·동의 필드)
4. 그 자리에서 시연용 demo 계정으로 로그인 (자세히 입력 안 함)
   - 이메일: `demo@d-connect.kr` / 비밀번호: `demo1234!`

### 멘트
> 가입 폼은 표시명·실명·연락처·소속까지 받습니다. 부트캠프 멘토링 과정에서
> "발표 시 누구한테 연락할지가 명확해야 한다"는 피드백을 반영했어요.
> 시연 편의를 위해 미리 만들어둔 데모 계정으로 로그인하겠습니다.

## 3. 대시보드 (2분) — "전체 데이터를 한눈에"

### 동선
1. 로그인 후 `/dashboard` 자동 이동
2. 상단 **통계 카드 4종** 짚어가기: 내 기업 4 · SDGs 분석 4 · 콘텐츠 10 · 편집한 콘텐츠 3
3. **SDGs 분포 도넛 차트** — 추천된 SDG 비율 (SDG 8·11·12·17이 어떻게 나뉘었는지)
4. **콘텐츠 유형 progress** — SNS·카드뉴스·숏폼·캠페인 슬로건 4종 분포
5. **좌측 사이드바**의 본인 기업 4곳을 가리키며 — 클릭으로 빠르게 이동 가능

### 멘트
> 로그인하면 본인의 모든 기업과 분석 결과가 한 곳에 모입니다.
> 오늘은 시연용으로 4개 기업이 사전에 등록돼 있어요 —
> 친환경 카페, 디지털 교육 사회적기업, 천안 마을상회, 공주 공예작가 협동조합.
> 차트는 본인의 분석 결과만 집계되니까 다른 사용자 데이터와 섞이지 않습니다.

**키 포인트**: 멀티테넌시(본인 데이터만) · 빈 상태 안 보이는 시연 안정성

---

## 4. 기업 상세 (1분 30초) — "오롯 친환경 카페"

### 동선
1. 사이드바에서 **"오롯 친환경 카페"** 클릭 → `/companies/{id}`
2. 상단 그라데이션 헤더 카드 (이니셜 아바타 + 기업명 + 업종·지역 메타)
3. SDGs 분석 완료 카드 → **"분석 결과 보기"** 또는 **"다시 분석"** 가능
4. 좌측 기본 정보 · 우측 활동 3개 (환경·지역경제·고용 카테고리별 배지·아이콘)
5. 우측 상단 **"정보 수정"** 버튼 짚기 — 기존 데이터 그대로 폼에 채워서 수정 가능

### 멘트
> 기업 한 곳을 들어가면 활동이 카테고리별로 정리됩니다.
> 이 카페는 **다회용 컵으로 일회용 컵 18,000개 절감**, **농가 6곳과 직거래**,
> **청년 바리스타 양성** — 환경·지역경제·고용 3가지 SDG 임팩트가 있죠.
> 활동을 수정하거나 추가하면 새로 분석할 수 있고, **기존 분석은 그대로 보존**됩니다.

---

## 5. SDGs 분석 결과 (3분) — "AI가 본 이 기업의 의미"

### 동선
1. 기업 상세에서 **"분석 결과 보기"** 클릭 → `/sdg-analysis/{id}`
2. 좌측 사이드 카드 — 기업 기본 정보 요약 + 사회적 기능 (환경·지역경제·고용)
3. 중앙 **SDG 매칭 카드 4장** — UN 공식 컬러로 SDG 8/11/12/17 (점수 + 키워드 + 근거)
4. 매칭 점수가 가장 높은 **SDG 12 (책임감 있는 소비)**, 92점 카드를 짚기
5. 하단 **콘텐츠 탭** — 전체/SNS/카드뉴스/숏폼/캠페인 슬로건 분기

### 멘트
> AI는 단순히 "이 기업은 SDG 12와 관련 있다"고 하지 않습니다.
> 각 SDG마다 **점수·키워드·근거 문장**을 같이 줘요.
> SDG 12 — 92점, 키워드는 다회용 컵·일회용품 감축·책임감 있는 소비.
> 근거는 "보증금 기반 다회용 컵으로 한 해 18,000개 절감 — 책임 있는 소비·생산의 모범 사례".
> 시연자가 발표 자료에 그대로 인용할 수 있는 수준의 문장이 나옵니다.

**키 포인트**: 단순 매칭이 아니라 **점수 + 키워드 + 근거 문장** 3종 세트

---

## 6. 콘텐츠 보기 + 편집 (2분) — "초안에서 완성까지"

### 동선
1. 분석 결과 페이지 하단 콘텐츠 탭에서 **SNS 게시글** 선택
2. 카드 펼치기 — 본문 + 해시태그 5개 + 이미지 프롬프트
3. **"편집"** 버튼 클릭 → `/contents/{id}` 진입
4. 본문 일부 수정 (예: 끝에 이모지 추가) → **"저장"**
5. 상단에 ✅ "저장되었습니다" 토스트 표시
6. 다시 분석 결과로 돌아가면 **"편집됨"** 노란 배지

### 멘트
> AI가 만든 건 어디까지나 **초안**입니다. 시연자가 직접 다듬을 수 있어요.
> 저장하면 곧바로 토스트로 알림이 가고, 편집 이력이 배지로 표시됩니다.
> 만약 결과가 마음에 안 들면 카드 우상단의 **"삭제"** 버튼으로 지우고
> 다시 생성할 수 있습니다.

## 7. 새 콘텐츠 생성 (옵션, 1분 30초)

> 시간이 남으면 시연. 짧으면 6번까지로 마무리.

### 동선
1. 분석 결과 페이지 상단의 **카드뉴스 생성 / 숏폼 생성** 같은 버튼 클릭
2. 진행 표시 (최대 30초) → 완료 토스트 → 새 콘텐츠 카드 추가

### 멘트
> 콘텐츠 유형은 4가지 — SNS 게시글, 카드뉴스, 숏폼 영상 스크립트, 캠페인 슬로건.
> 한 번 분석된 기업이면 언제든 같은 분석 위에서 새 유형을 추가로 생성할 수 있습니다.

## Q&A 예상 질문 + 답변 키워드

| 질문 | 답변 키워드 |
|---|---|
| AI가 만든 콘텐츠의 신뢰도는? | 톤 가드: 광고성·과장·검증되지 않은 수치 회피 (PRD §5.3). 모든 초안은 편집 가능, 사용자가 마지막 책임. |
| 비용은 누가 부담? | Anthropic Claude 호출은 백엔드 경유. 분석 1건당 비용 대략 ~10원 추산. 시연 단계에선 부트캠프 예산. |
| 데이터 보안 / 개인정보? | DB는 로컬 SQLite (시연용). 본인 데이터만 조회되도록 멀티테넌시 적용 (ADR-0005). 운영 단계 진입 시 PostgreSQL + 클라우드 검토. |
| 왜 SDGs인가요? | 공공기관·지자체 사업 신청에서 SDG 매칭 요구가 늘어남. 작은 기업도 "우리 활동이 어떤 SDG와 연결되는지" 한 줄로 답할 수 있게. |
| 4가지 SDG만 다루는 이유? | SDG 8 (양질의 일자리), 11 (지속가능한 도시), 12 (책임감 있는 소비), 17 (파트너십) — 지역 기반 소상공인 활동과 가장 자주 매칭되는 4개로 한정. 향후 확장 가능. |
| Anthropic이 응답 못 하면? | mock fallback이 동일 스키마의 안전 응답을 반환 + 결과 페이지 상단에 노란 배너로 "mock 결과" 안내. 시연 중단 위험 차단. |

## 시연 시 자주 하는 실수 방지

1. **dev 서버에서 시연하지 마세요** — 빨간 에러 overlay가 발생하면 매우 어색합니다. `pnpm build && pnpm start`로 production 모드.
2. **`.env` 확인** — `ANTHROPIC_API_KEY`가 비어있으면 분석 결과 페이지 상단에 노란 배너. 의도적으로 보여주려는 게 아니면 키 설정.
3. **새 콘텐츠 생성 시 대기 시간** — 실제 호출은 최대 30초 걸릴 수 있습니다. progress bar로 진행 중임을 안내.
4. **데모 데이터 새로고침** — 시연 직전 `pnpm db:seed` 한 번 더 실행하면 데모 데이터 깨끗하게 리셋 (사용자가 시연 중 만든 데이터 함께 사라지는 점 주의).
