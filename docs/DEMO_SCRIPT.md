> 2026-06-25 발표용. 총 12~15분 시연 + 3~5분 Q&A. 시연자가 화면을 보면서 그대로 따라
> 읽을 수 있도록 멘트와 동선까지 적었다.
>
> **v2 (2026-06-12)**: AI 파이프라인 개편(#93~#105)·실제 기업 데이터(#107) 반영 전면 개정.
> 시연 주인공은 **유클리드소프트** — 부트캠프 주최 기업이라 청중이 가장 잘 아는 회사다.

## 0. 사전 체크리스트 (시연 30분 전)

### 서버·환경
- [ ] 노트북 + 외부 모니터 연결, 해상도 1920×1080 (또는 발표 환경에 맞춤)
- [ ] **production 빌드로 실행** — `pnpm build && pnpm start` (dev overlay 등 방해 요소 차단)
- [ ] **ngrok 터널 실행** — `pnpm tunnel` (참가자 휴대폰 접속 + 인증 메일 링크용)
  - `.env`의 `AUTH_URL`이 ngrok 도메인인지 확인 — 꺼져 있으면 메일 링크·소셜 로그인이 깨진다
- [ ] `.env` 키 3종 확인:
  - `OPENAI_API_KEY` — 비어 있으면 분석·생성이 전부 mock (노란 배너 표시됨)
  - `EMAIL_SERVER` / `EMAIL_FROM` — 비어 있으면 참가자 가입 시 인증 메일 대신 화면에 링크 표시
  - `AUTH_URL` — ngrok 도메인
- [ ] 외부 인터넷 연결 확인 (OpenAI API + SMTP)

### 시연 준비물
- [ ] **참가자 접속용 QR 코드** — ngrok 주소를 QR로 출력/슬라이드에 삽입
- [ ] **ChatGPT 로그인된 탭** 미리 열어두기 (포스터 이미지 생성용 — 최신 이미지 모델)
- [ ] **백업 산출물 폴더** 열어두기 — 사전 생성한 포스터·카드뉴스 이미지 (이미지 생성이 1~2분
      걸리므로, 생성 대기 중 보여주거나 네트워크 장애 시 대체)
- [ ] 브라우저 새 시크릿 창 + DevTools 닫기, 데모 계정 로그아웃 상태

### 시연 계정·데이터
- 이메일: `demo@d-connect.kr` / 비밀번호: `demo1234!`
- 등록 기업: **유클리드소프트** (실제 정보 — 분석 1건: SDG 8 100점·11 80·12 80·17 70 + 콘텐츠 다수)
- `pnpm db:seed`는 demo 계정만 보장하는 **비파괴** 스크립트 — 실행해도 유클리드소프트 데이터는 유지됨

### 백업 시나리오 (장애 대비)
| 장애 | 대처 |
|---|---|
| OpenAI 호출 실패/지연 | mock fallback이 자동 동작 — 노란 배너를 가리키며 "장애 시에도 흐름이 끊기지 않는 설계"로 설명 전환 |
| 이미지 생성 1~2분 지연 | 대기 중 백업 산출물 탭으로 전환해 "방금 같은 프롬프트로 미리 생성한 결과" 제시 |
| 인증 메일 미도착 | "스팸함 확인" 안내 → 그래도 없으면 흐름 설명만 하고 진행 (가입 자체는 인증 없이도 이용 가능) |
| ngrok 끊김 | 참가자 시연 생략, localhost로 본 시연만 진행 |

## 1. 인트로 (1분) — "왜 D-Connect인가요"

> 대전·세종·충남에는 작지만 의미 있는 활동을 하는 소상공인과 사회적경제기업이 많습니다.
> 환경, 지역 농가, 청년 일자리 — 좋은 일을 하고 있는데 **그걸 알리는 콘텐츠를 만들 여력이
> 없습니다.** SNS 글 하나, 포스터 한 장이 이분들에겐 큰 일이거든요.
>
> D-Connect는 그 작업을 AI가 대신합니다. 기업 활동을 입력하면 **유엔 지속가능발전목표(SDGs)**
> 와 연결해 분석하고, 홍보 콘텐츠까지 만들어줍니다.
>
> 오늘 시연의 주인공은 — 바로 이 부트캠프를 주최한 **유클리드소프트**입니다.
> 실제 기업 정보로 처음부터 끝까지 보여드리겠습니다.

**키 메시지**: 작은 기업의 좋은 이야기를 SDGs라는 공공의 언어로, 분석부터 포스터까지 한 흐름에

## 2. (참여형) 참가자 가입 (1분 30초) — "직접 해보세요"

> 청중 참여 코너. 발표 환경이 안 되면 생략하고 3번으로.

### 동선
1. 슬라이드에 **QR 코드** 표시 — "휴대폰으로 접속해 보세요"
2. 참가자들이 가입하는 동안: 회원가입 폼을 화면에 띄우고 설명
   - 연락처 자동 하이픈, 약관 동의, 소셜 로그인(카카오·구글)도 지원
3. **"가입하면 입력하신 이메일로 실제 인증 메일이 갑니다"** — 메일함 확인 유도

### 멘트
> 지금 QR로 접속하시면 직접 가입해 보실 수 있습니다. 가입하면 진짜 인증 메일이 발송돼요.
> 카카오·구글 간편 로그인도 됩니다. 계정 찾기, 비밀번호 재설정, 회원탈퇴까지 —
> 계정 수명주기 전체가 구현되어 있습니다.

**키 포인트**: 데모용 껍데기가 아니라 실제 동작하는 인증 체계 (이메일 인증·계정 복구·탈퇴)

## 4. 기업 정보 (1분 30초) — "유클리드소프트"

### 동선
1. 내 기업 → **유클리드소프트** 클릭
2. 기본 정보(2014년 설립·법인·서비스·대전 서구·타겟 청년/지역주민·홍보 목표) 짚기
3. 활동 3개: **ABC 부트캠프**(고용) · **기술 나눔 ESG 프로젝트**(협력) · **AI 무단투기 감지**(환경)

### 멘트
> 등록 폼에서 받은 정보가 전부 AI 분석에 들어갑니다 — 업종, 사업자 형태, 지역,
> 타겟, 홍보 목표까지요. 활동을 보시면 익숙하실 겁니다. 여러분이 듣고 계신
> **ABC 부트캠프**가 첫 번째 활동이에요. 2025년 6~9기 120명 참여, 113명 수료.

## 5. SDGs 분석 결과 (2분 30초) — "AI가 본 유클리드소프트"

### 동선
1. **"분석 결과 보기"** → `/sdg-analysis/{id}`
2. SDG 매칭 카드 4장 (UN 공식 컬러): **SDG 8 — 100점** · SDG 11 — 80 · SDG 12 — 80 · SDG 17 — 70
3. SDG 8 카드의 키워드·근거 문장 읽기 (청년·기술·고용·교육)
4. 좌측 사회적 기능 분류(고용·공동체·협력·환경)와 공공적 의미 요약

### 멘트
> AI는 "관련 있다"로 끝나지 않고 SDG마다 **점수·키워드·근거 문장**을 줍니다.
> SDG 8 양질의 일자리 — 100점. 근거: "ABC 부트캠프를 통해 미취업 청년에게 데이터·AI
> 교육을 제공하고 고용 기회를 확대." 발표 자료에 그대로 인용할 수 있는 문장이 나옵니다.
> 참고로 입력에 없는 수치는 만들어내지 않도록 가드가 걸려 있습니다 — 120명, 94% 같은
> 숫자는 전부 입력한 활동 설명에 실재하는 값입니다.

**키 포인트**: 점수+키워드+근거 3종 세트 · 수치 환각 가드

---

## 6. 콘텐츠 생성 (3분) — "분야 골라서, 옵션 맞춰서"

### 동선
1. 분석 페이지의 생성 위젯: **① 홍보할 SDGs 분야** — SDG 8 선택 (UN 컬러 칩)
2. **② 콘텐츠 종류** — 카드뉴스 선택 → **③ 세부 설정** 패널이 열림
3. 옵션 보여주기: 대상 SNS(인스타그램), 비율(1:1 추천), **카드 수 4장**, 이미지 스타일(일러스트),
   추가 요청("부트캠프 수료율을 강조해줘") 입력
4. **✨ 생성하기** → 진행 바 + 단계 메시지 + 스켈레톤 (5~15초)
5. 완료 토스트 → 새 카드: [1장]~[4장] 본문 + 해시태그 + 접힌 생성 프롬프트
6. 카드 헤더의 메타("인스타그램 · 1:1 · 일러스트 · 4장")와 SDG 뱃지 짚기

### 멘트
> 어떤 SDG를 홍보할지 고르고, 어디에 올릴지·몇 장으로 만들지·그림체까지 정합니다.
> X(트위터)를 고르면 본문을 280자 이내로 맞춰줄 정도로 옵션이 실제 반영돼요.
> 카드뉴스는 요청한 장 수대로 정확히 나오고, 장마다 카드 생성 프롬프트가 따라옵니다.

**키 포인트**: SDG 분야 선택 → 유형 → 세부 설정의 3단계 · 옵션이 출력에 실제 반영

## 7. 하이라이트: 포스터 원샷 생성 (2분 30초) — "프롬프트 복사 → 완성 포스터"

### 동선
1. 같은 위젯에서 **포스터** 선택 → 비율 2:3(추천) → 생성
2. 결과 카드: 포스터 문구([헤드라인]/[서브카피]/[하단 정보]) + **📋 복사** 버튼
3. 프롬프트 복사 → 미리 열어둔 **ChatGPT 탭**에 붙여넣기 → 이미지 생성 시작
4. **대기 1~2분 동안**: 백업 산출물 탭으로 전환 — "같은 프롬프트로 미리 생성한 결과"
   (한글 문구가 완벽히 박힌 완성 포스터) 먼저 보여주기
5. ChatGPT 생성이 끝나면 라이브 결과로 복귀

### 멘트
> 포스터는 한 단계 더 갑니다. 생성된 프롬프트에는 **한국어 문구와 배치 지시까지** 들어있어서,
> 최신 이미지 AI에 붙여넣으면 — 보시는 것처럼 **헤드라인·서브카피·기업명이 전부 박힌
> 완성 포스터가 한 번에** 나옵니다. 디자이너 없이 소상공인이 점심시간에 만들 수 있는 수준이죠.
> 글자가 깨지지 않도록 한글 정확성 가드, 가짜 로고 방지 같은 프롬프트 엔지니어링이
> 들어가 있습니다.

**키 포인트**: 시연 전체의 와우 모먼트 — 입력부터 완성 포스터까지 끊김 없는 동선

## Q&A 예상 질문 + 답변 키워드

| 질문 | 답변 키워드 |
|---|---|
| AI가 만든 콘텐츠의 신뢰도는? | 톤 가드(광고·과장·검증 안 된 수치 금지, PRD §5.3) + 수치 환각 가드(입력에 있는 숫자만 인용). 모든 초안 편집 가능 — 최종 책임은 사용자. |
| 어떤 AI를 쓰나요? 비용은? | 텍스트는 OpenAI gpt-4o-mini(분석·생성 1건당 수 원 수준), 이미지는 사용자가 본인 ChatGPT 등에서 생성(프롬프트만 제공) — 서비스 운영 비용 최소화 구조. 모델은 환경변수로 교체 가능. |
| 한글이 들어간 이미지가 어떻게 가능한가요? | 최신 이미지 모델(gpt-image-2급)이 한글 렌더링 가능해짐. 프롬프트에 문구 정확 인용 + 한글 글리프 가드 + 글자 수 최소화 설계를 넣어 깨짐을 방지. |
| 장애가 나면? | OpenAI 실패·타임아웃 시 동일 스키마 mock 응답으로 폴백 + 화면에 명시 배너. 시연·서비스가 멈추지 않는다. |
| 데이터 보안 / 개인정보? | 본인 데이터만 조회(멀티테넌시, ADR-0005). 이메일 인증·비밀번호 재설정 토큰은 해시 저장·일회용. 시연 DB는 로컬 SQLite, 운영 시 PostgreSQL 검토. |
| 왜 SDGs 4개(8·11·12·17)만? | 지역 소상공인 활동과 가장 자주 매칭되는 4종으로 한정해 분류 품질 확보. 구조상 확장 용이. |
| 콘텐츠 유형은? | SNS 게시글(완성 텍스트)·카드뉴스(장별 문안+장별 카드 프롬프트)·숏폼(장면별 영상 프롬프트)·포스터(한글 문구 포함 완성형 프롬프트). |

## 시연 시 자주 하는 실수 방지

1. **dev 서버로 시연하지 마세요** — `pnpm build && pnpm start` (production 모드).
2. **ngrok·AUTH_URL 짝 확인** — 터널이 꺼져 있으면 참가자 접속·인증 메일 링크·소셜 로그인이
   전부 깨집니다. `pnpm tunnel` 실행 + 200 응답 확인.
3. **`OPENAI_API_KEY` 확인** — 비어 있으면 전부 mock + 노란 배너. (반대로 mock 시연을
