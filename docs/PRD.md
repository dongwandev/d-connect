## 1. 배경 및 목적

### 1.1 한 줄 정의

**D-Connect는 대전·세종·충남권 소상공인 및 사회적경제기업이 지역사회 기여 활동을 SDGs와 연결해 공공홍보 콘텐츠로 활용하기 위한 AI 기반 웹 프로토타입이다.**

### 1.2 문제 정의

대전·세종·충남권의 소상공인 및 사회적경제기업은 지역 고용, 친환경 소비, 로컬푸드, 지역 행사 참여, 지자체·공공기관 협력 등 다양한 방식으로 지역사회에 기여하고 있다. 그러나 이러한 활동은 보통 제품 소개나 SNS 홍보 문구 안에서 짧게 언급되는 수준에 그쳐, **기업이 가진 사회적 가치와 공공적 의미가 충분히 드러나지 않는다.**

현재는 기업 담당자가 직접 홍보 문구를 작성하거나 일반 AI 도구로 SNS 게시글·카드뉴스·광고 문구를 생성하는 방식으로 해결하고 있다. 이 방식은 다음의 한계가 있다.

- 기업 활동이 어떤 SDGs 목표와 연결되는지 사용자가 직접 판단해야 한다.
- SDGs 연결 근거와 사회적 기능을 공공기관이 검토할 수 있는 문장으로 정리하기 어렵다.
- 일반 AI 콘텐츠 생성은 홍보 문안 중심이라 지역상생·공공성·지속가능성의 근거가 약하다.
- 지자체·공공기관·지역상생 캠페인에서 바로 활용하기엔 표현이 과장되거나 광고성으로 흐를 수 있다.
- 기업별 분석 결과와 생성 콘텐츠를 다시 조회·수정하는 관리 흐름이 부족하다.

### 1.3 제품의 차별점

D-Connect는 단순 홍보 문구 생성 도구가 아니라, **지역 기업의 활동 정보를 입력하면 SDGs 연계 가능성·연결 근거·사회적 기능·공공홍보 콘텐츠 초안을 한 번에 제공하는 도구**다. 일반 AI 콘텐츠 도구와의 핵심 차이는 다음과 같다.

- **공공성 우선** — 광고성 문구보다 공공기관·지자체가 그대로 활용할 수 있는 톤·근거 중심
- **SDGs 매핑 내장** — 활동 키워드 → SDGs 자동 추천 + 매칭 근거 제시
- **검토 가능성** — 생성 결과는 항상 사람이 수정 가능한 초안으로 제공

## 2. 타겟 사용자

### 페르소나 1 — 지역 소상공인·사회적경제기업 홍보 담당자

- 대전·세종·충남권에서 사업을 운영하거나 홍보를 맡고 있는 **20~40대 실무자**
- 제품·서비스 홍보는 해본 경험이 있지만 SDGs, 공공홍보, 지역상생 메시지 작성에는 익숙하지 않음
- 지자체 사업, 지역 캠페인, 공공기관 협업 자료에 넣을 수 있는 **신뢰성 있는 소개 문구**가 필요함

### 페르소나 2 — 지자체·공공기관 지역상생 캠페인 담당자

- 지역 기업 사례를 발굴해 캠페인, 카드뉴스, 보도자료, SNS 콘텐츠로 소개해야 하는 실무자
- 단순 기업 홍보보다 **고용·환경·지역경제·공동체·협력 관점의 공공적 의미**를 정리해야 함
- 여러 기업의 활동을 같은 기준으로 비교·정리하고, 검토 가능한 콘텐츠 초안을 빠르게 확보하고 싶어 함

## 3. 핵심 기능 (MVP)

v1에서는 발표 가능한 웹 프로토타입을 목표로 하며, **입력 → 분석 → 콘텐츠 생성 → 저장 → 조회**까지의 핵심 흐름만 구현한다.

### 3.1 기업 및 활동 정보 입력

- 기업명, 업종, 소재 지역, 제품·서비스, 홍보 목적을 입력한다.
- 지역사회 기여 활동, 친환경 활동, 고용 창출 활동, 협력 사례 중 **최소 1개 이상의 활동 정보**를 입력한다.

### 3.2 SDGs 목표 추천 및 연계 근거 설명

- 입력된 활동 내용을 기반으로 **관련성이 높은 SDGs 목표를 추천**한다.
- MVP에서는 **SDG 8, SDG 11, SDG 12, SDG 17**을 우선 지원한다.
- 추천 목표별로 **매칭 키워드, 추천 점수, 연결 근거**를 함께 보여준다.

### 3.3 사회적 기능 및 공공적 의미 도출

- 기업 활동을 **고용 / 환경 / 지역경제 / 공동체 / 협력** 관점으로 분류한다.
- 공공기관·지자체·지역상생 캠페인에서 활용할 수 있는 의미를 요약한다.

### 3.4 SDGs 기반 공공홍보 콘텐츠 생성

- **SNS 게시글 / 카드뉴스 문안 / 숏폼 영상 대본 / 캠페인 슬로건** 중 콘텐츠 유형을 선택해 초안을 생성한다.
- 결과에는 **본문, 해시태그, 이미지 생성 프롬프트, 수정 가능한 초안**을 포함한다.
- 과장 광고나 검증되지 않은 수치 없이 공공홍보에 맞는 문체를 사용한다.

### 3.5 결과 저장·조회·수정

- 기업 정보, SDGs 분석 결과, 생성 콘텐츠를 저장한다.
- 저장된 결과를 **목록과 상세 화면**에서 다시 확인한다.
- 생성된 콘텐츠 초안은 사용자가 직접 수정하고 저장할 수 있어야 한다.

## 4. 사용자 시나리오

### 시나리오 A — 소상공인 홍보 담당자의 SNS 게시글 작성

대전의 한 친환경 카페 사장 김씨는 지역 카페 모임에서 진행한 일회용품 줄이기 캠페인을 SNS에 알리고 싶다. 일반 AI 도구로 문구를 만들었더니 광고성 표현만 나와 사용하기 어려웠다.

1. D-Connect에 접속해 카페 정보(상호, 업종, 소재지)와 캠페인 활동 내용을 입력한다.
2. SDG 12(지속가능한 소비와 생산) 추천 + 매칭 키워드("일회용품 저감", "다회용 컵") + 연결 근거를 확인한다.
3. "공동체"·"환경" 관점에서 정리된 사회적 의미 요약을 본다.
4. 콘텐츠 유형으로 **SNS 게시글**을 선택해 초안을 생성한다.
5. 광고성 표현 없이 작성된 본문 + 해시태그를 확인하고, 자신의 말투에 맞게 일부 수정한다.
6. 수정본을 저장하고, 실제 SNS에 게시한다.

### 시나리오 B — 지자체 담당자의 카드뉴스 자료 정리

세종시 지역상생 캠페인 담당자 박씨는 이번 분기 카드뉴스에 소개할 지역 기업 3곳을 선정해야 한다. 기업마다 활동이 달라 같은 기준으로 정리하기 어렵다.

1. D-Connect에 각 기업 정보와 활동을 입력한다 (또는 사전 입력된 예시 기업을 조회).
2. 기업별 SDGs 추천 결과와 사회적 기능 분류(고용/환경/지역경제/...)를 같은 화면에서 비교한다.
3. 콘텐츠 유형으로 **카드뉴스 문안**을 선택해 기업별 초안을 생성한다.
4. 검토 후 일부 문구를 수정하고 저장한다.
5. 저장된 초안을 카드뉴스 디자인 단계로 넘긴다.

## 5. 비기능 요구사항

### 5.1 보안

- AI API 키는 **서버에서만 보관**한다. 클라이언트에 노출되지 않는다.
- 사용자 입력 데이터는 클라이언트 외부로 노출되지 않는 경로로만 처리한다.

### 5.2 안정성 (발표 시연 우선)

- AI API 호출 실패 또는 키 부재 시에도 **mock 응답으로 흐름이 유지**되어야 한다.
- 발표 시연 중 입력 → 분석 → 생성 → 저장 → 조회 흐름이 **끊기지 않도록** 한다.

### 5.3 콘텐츠 품질

- 과장된 성과, 검증되지 않은 수치, 허위 사실, 지나친 광고성 표현은 **생성하지 않는다**.
- 결과물은 **공공홍보에 적합한 문체**로 유지한다.
- 모든 생성 결과는 **최종 확정물이 아닌 사람이 검토·수정할 수 있는 초안**으로 제공한다.

### 5.4 운영

- 발표 시연 및 결과보고서용으로 **예시 기업 데이터 2~3개**를 사전 준비한다.

### 5.5 호환성

- **데스크탑 웹 브라우저**(최신 버전 Chrome/Edge) 우선 지원.
- 모바일 반응형은 선택 사항(시연 시연 위주이므로 우선순위 낮음).

## 6. 범위 외 (Out of Scope)

MVP에서는 아래 항목을 포함하지 않는다.

- 일반 사용자 회원가입 및 로그인
- 기관별 권한 관리
- 외부 공공데이터 자동 연동
- SNS 자동 게시
- 카드뉴스 이미지 자동 편집
- 숏폼 영상 자동 생성 및 렌더링
- 결제 기능
- 다국어 콘텐츠 생성
- 고도화된 통계 대시보드
- 마케팅형 랜딩 페이지 (첫 화면은 바로 기업 정보 입력으로 시작)

## 8. 기술 스택 (참고)

상세 의사결정은 [ADR-0001 기술 스택](adr/0001-tech-stack.md)에서 다룬다.

- **프레임워크:** Next.js (App Router) + TypeScript
- **ORM / DB:** Prisma + SQLite
- **AI:** SDGs 추천은 **키워드 기반 규칙 분석 + LLM 생성 결과 혼합**
- **호출 경로:** 프론트엔드는 AI API를 직접 호출하지 않고, **백엔드 API를 경유**한다.
